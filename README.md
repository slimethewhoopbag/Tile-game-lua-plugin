# Tile game

Game scripts live in `game/`, laid out to mirror the Roblox instance tree.
Start there: `game/README.md` has the folder-to-instance path map.

The Luau skills and the anti-ai commit guardrail still run during sessions.
Their files sit in the hidden `.claude/`, `.agents/`, and `anti-ai/` folders so
they stay out of the way while you read the game.
